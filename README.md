# PFI · Prep For Interview

iOS-приложение для подготовки к техническому собеседованию: вопросы и практические
задачи с интервальными повторениями.

Приложение не просто хранит список вопросов, а определяет, что и когда показать,
чтобы материал закрепился в памяти.

## Возможности

- **Вопросы** по темам, с полнотекстовым поиском и фильтрами
- **Задачи** с прогрессивными подсказками и полем для собственного решения
- **Интервальные повторения** по алгоритму SM-2 — вопрос возвращается до того, как забудется
- **Заметки** к любому вопросу с поддержкой Markdown
- **Режим собеседования** — случайные вопросы с таймером и отчётом по слабым темам
- **Статистика**: прогресс по темам, карта активности, серия дней
- **Локальные уведомления** о накопившихся повторениях
- **Экспорт и импорт** данных в Files / iCloud Drive

## Стек

`iOS 26` · `SwiftUI` · `Swift 6` (strict concurrency) · `SwiftData` · `Swift Charts`
`Swift Testing` · `MVVM + Repository + DI` · без зависимостей в рантайме

## Архитектура

```
View (SwiftUI)
  │  @Bindable
ViewModel  @MainActor @Observable
  │  протокол, async
Repository (actor)  ──▶  SwiftData
  │
  └─ наружу только Sendable DTO
```

Ключевые решения:

- **Слой данных изолирован в акторе.** `@Model`-объекты SwiftData не покидают репозиторий —
  наружу уходят неизменяемые `Sendable`-структуры. Поток данных однонаправленный,
  ViewModel тестируется без базы.
- **Swift 6 language mode с самого начала.** Ошибки потокобезопасности ловятся компилятором,
  а не в проде.
- **Без `@Query` во вью.** Идиоматично для SwiftData, но привязывает представление к базе
  и лишает возможности подставить мок.
- **Типизированный роутер** вместо разрозненных `NavigationLink` — даёт deep links
  и восстановление стека навигации.

## Структура

```
PFI/
├── App/           точка входа, DI-контейнер, роутер
├── Core/          модели, DTO, репозитории, сервисы
├── DesignSystem/  токены и переиспользуемые компоненты
├── Features/      экраны: вопросы, задачи, квиз, статистика
└── Resources/     ассеты, локализация
```

## Запуск

```bash
git clone https://github.com/KorolSwift/PFI.git
cd PFI
open PFI.xcodeproj
```

Требуется Xcode с iOS 26 SDK. Внешние зависимости ставить не нужно.

Репозиторий содержит демонстрационный набор вопросов. Личная база пользователя хранится
на устройстве и в репозиторий не входит.

## Инструменты

`Tools/import_questions.py` — идемпотентный импорт вопросов из Markdown в JSON.
Идентификатор вычисляется из текста вопроса, поэтому повторный импорт обновляет запись,
а не создаёт дубль, и прогресс пользователя не теряется.
